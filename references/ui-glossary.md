# UI Glossary

Recommended Arabic for common UI concepts, based on what the reference brands actually use. "Recommended" is the safest pan-Arab choice; alternatives are valid when a profile or existing project strings call for them. **Existing project terms always win** — check the repo's Arabic files first.

Buttons below are shown in the imperative convention; the verbal-noun equivalent is listed where products commonly use it (Google-style UIs).

## Contents
Account & auth · Navigation & general · Actions · Commerce & orders · Payments & fintech · Forms & validation · Status & feedback · Settings & privacy · Marketing CTAs · Telecom (Egypt/GCC)
